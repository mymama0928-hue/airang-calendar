# 에이랑 공용달력

지수·하림·지영이 각자 구글 계정으로 로그인하면 각자의 구글 캘린더 일정이 자동으로 올라오고,
셋이 다같이 비는 날(모일 수 있는 날)을 찾아 주는 공용 달력입니다.

- 사람마다 형광색으로 구분 (지수 핑크 · 하림 라임 · 지영 시안 · 에이랑 공통 주황)
- 대시보드: 다같이 모일 수 있는 날 / 다음 일정 / 선택한 날 / 앞으로 7일 — 시간과 장소 표시
- 일정 직접 추가·수정·삭제, 모두에게 실시간 반영
- 구글 캘린더 동기화: 페이지를 연 사람의 캘린더를 5분마다 다시 읽음

## 처음 한 번 설정 (지수님)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com → **프로젝트 추가** → 이름 `airang-calendar` → 만들기 (애널리틱스는 꺼도 됨)
2. 왼쪽 **빌드 → Authentication → 시작하기 → 로그인 방법 → Google → 사용 설정 → 저장**
3. Authentication → **설정 → 승인된 도메인 → 도메인 추가** → `mymama0928-hue.github.io`
4. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
5. Firestore → **규칙** 탭 → `firestore.rules` 내용을 붙여 넣고, 이메일 3개를 실제 이메일로 바꾼 뒤 **게시**
6. 프로젝트 설정(톱니바퀴) → **내 앱 → 웹(</>)** → 앱 등록 → 나오는 `firebaseConfig`의 `apiKey`, `authDomain`, `projectId`, `appId`를 복사

### 2. 구글 캘린더 읽기 허용 (Google Cloud 콘솔, 같은 프로젝트)
1. https://console.cloud.google.com → 위쪽에서 프로젝트 `airang-calendar` 선택
2. **API 및 서비스 → 라이브러리** → `Google Calendar API` 검색 → **사용**
3. **API 및 서비스 → OAuth 동의 화면**(Google 인증 플랫폼) → 대상: **외부**, 상태: **테스트** → **테스트 사용자**에 지수·하림·지영 구글 이메일 3개 추가
4. **데이터 액세스(범위)** → 범위 추가 → `.../auth/calendar.readonly` 체크 → 저장
5. **사용자 인증 정보** → `Web client (auto created by Google Service)` 클릭 → **승인된 자바스크립트 원본**에 `https://mymama0928-hue.github.io` 추가 → 저장 → **클라이언트 ID** 복사

### 3. config.js 채우기
`config.js`에 1-6의 값과 2-5의 클라이언트 ID를 넣고 저장(커밋)하면 끝.

## 쓰는 법
- 링크를 열고 **구글 계정으로 로그인** → 처음 한 번 이름(지수/하림/지영) 선택 → 내 일정이 자동으로 올라감
- 구글 로그인 창에서 "확인되지 않은 앱" 경고가 나오면 **고급 → 이동**을 누르면 됩니다 (우리끼리 쓰는 테스트 앱이라 나오는 경고).
- 구글 캘린더 권한은 1시간마다 만료돼요. 위쪽 **‘구글 동기화’** 버튼이 빨갛게 바뀌면 한 번 눌러 주세요.
- 구글 캘린더 동기화는 **본인이 페이지를 열어 둔 동안** 일어나요. 닫아 둔 사이 바뀐 일정은 다음에 열 때 반영됩니다.
